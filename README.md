# Illuminz – Motion page (responsive HTML/CSS)

Static, responsive build of the Figma "Motion" page (node 11687-23265).

- `index.html` – semantic markup
- `styles.css` – mobile-first styles (breakpoints: 640px, 900px, 1024px)

## Assets
Drop exported Figma images into `assets/` with these names (the page shows tinted placeholders until they exist):

| File | Section |
|---|---|
| `storyboarding.png` | Storyboarding illustration |
| `explainer-videos.png` | Explainer Videos illustration |
| `character-animation.png` | Character Animation illustration |
| `lottie-animations.png` | Lottie Animations screenshot |
| `lovable.svg`, `figma.svg`, `webflow.svg` | Tool icons |

The hero 3D shapes are pure CSS; replace them with exported PNGs if you need pixel-exact renders.
